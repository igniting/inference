# Contributing

The book is in outline review. Please open an issue before drafting a chapter so
the thesis, scope, and evidence plan can be agreed first.

## Chapter proposal

A proposal should include:

- the reader question the chapter answers;
- prerequisites and concepts introduced;
- the new system trace, diagram, and experiment it will use;
- primary sources and exact repository revisions;
- likely failure modes and counterexamples; and
- how the chapter differs from existing published explanations.

All work must follow the
[research and originality policy](src/research-method.md). Do not submit text
that copies or closely paraphrases a source, including source documentation.

## Local checks

```bash
mdbook build
```

Check links, headings, code samples, citations, and generated figures before
requesting review. Performance claims must include reproducibility artifacts.
